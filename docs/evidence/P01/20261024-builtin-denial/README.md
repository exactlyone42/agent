# 拒絕命令後，測試檔案沒有被寫入

使用本機 Codex app-server 與固定假模型回應，請內建命令工具改寫暫存測試檔。收到授權要求後回覆拒絕，檔案仍是原值；同一命令改成允許後，檔案變成 changed，原本的拒絕檢查退出 1。兩次程序都正常退出。

七項執行檢查及七項原始紀錄核對通過。未呼叫付費模型、未修改使用者資料、未部署。模型即使宣稱完成，也不作為驗收依據。

第一次核對誤把帶有 shell 引號的命令當成以檔名結尾，判定失敗；原始結果保留在 first-check-failure。修正後核對程序提供的完整動作欄位。negative-accept 保留真正放行命令的失敗對照。

本機模型建議把授權回覆送到模型 HTTP 端點，與實際程序介面不符，未採用；以本機匯出的 schema 與實際事件核對後修改。

範圍只涵蓋這一個內建命令的允許與拒絕。尚未驗證所有工具、重啟、Rig、Tauri、變異測試、覆蓋率與全套品質，不提交或宣稱 P01 完成。執行證據含程式版本、雜湊與時間，見 manifest.json。
