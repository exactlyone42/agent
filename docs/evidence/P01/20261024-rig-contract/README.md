# Rig 工具授權與參數試接

固定版本已接成可編譯的 Rust 測試。工具只回傳合成文字，不讀寫真實檔案，不呼叫付費模型；P01 未完成。

允許時工具執行一次，固定回傳值出現在下一次模型請求。拒絕或參數格式錯誤時不執行工具，並回報錯誤。刻意把拒絕改成允許後，測試退出 101，抓到工具多執行一次；之後已恢復原碼。

Rig 預設會把參數錯誤交回模型，模型仍可回覆 done。`final-test.txt` 保存要求回報錯誤時的失敗；加入執行前參數檢查後，`validated-test.txt` 的兩項測試通過。模型文字不能當成任務成功證據。

Rust 格式、嚴格靜態檢查、兩項測試及共用 Git 規則的 22 項測試通過。全檔變異、覆蓋率、串流、取消、重啟、真檔案工具、Tauri 與完整品質未驗；未提交、推送或部署。Rust 三項檢查已加入既有 Git 規則，原要求未降低。

Rig 固定來源為 `55cd481a2421fd5da468b5bd6afc6ac876883599`；MIT 授權保存在 `rig-LICENSE.txt`，依賴版本記於根目錄 Cargo.lock。第一次下載因內建 SSH 驗證失敗，改用既有 Git CLI 後成功，未改全域設定。

持有原獨占鎖時，競爭取鎖退出 1。原排程讀回啟用且每五分鐘執行。下一步補齊兩候選的串流、取消及重啟契約，再決定底座與建立桌面。
