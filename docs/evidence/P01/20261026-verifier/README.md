# 成果驗證元件

`crates/agent/src/verification.rs` 是實際元件，不再只由測試自己比字串。呼叫者提供已授權開啟的一般檔案與任務固定的預期位元組；元件從檔首讀取，最多讀預期長度加一位元組，錯字、少字、多字、無法讀取或特殊檔案都不通過。

Rig 比較測試讓寫入工具交出同一個已開啟檔案，再呼叫此元件。固定模型可以回答 done，但缺少成果或內容不符仍無法取得驗證通過。這證明執行與驗證流程，不證明模型有理解、推導或轉換文件的能力。

Claude 原件為 review-prompt.txt／review-result.json。依審查補上空預期加非空成果、拒絕特殊檔案，並改為交出同一個檔案；移除測試中重複整檔讀取。正式 CLI 整合仍未做。修改已重跑測試，沒有再送一輪審查。

最新同版結果見 manifest.json、review-fixes/coverage.json 及 review-fixes/mutants.out/outcomes.json。7 項測試通過；核心驗證檔的 5 個生成變異全部被測試抓到。這不代表所有可能錯誤均被涵蓋；測試輔助程式不在自動變異掃描內。早期 2 個變異的結果保留在上一層 mutants.out。

界線：只驗該檔案的內容，不保證發布路徑仍指向同一個檔案，不保證其他副作用、安全隔離、檔案系統不變或持續有效。位元組上限不等於網路磁碟的時間上限。這些仍須正式任務／工具整合處理，不能把單一函式通過當成任務或產品完成。僅 Linux x64 已跑；Windows／macOS 與真人未跑。
