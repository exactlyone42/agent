# Rig 已知問題對照：我們的檢查與測試項目

用途：Rig 公開 issue 已替我們踩過的坑，轉成 agent-harness 與 agent-harness-openai 的檢查項目。每項寫成測試後才能勾選；沒有測試證據不得宣稱通過。

來源：0xPlaygrounds/rig 最近 300 個 issue（2026-10-28 查，其中 65 個標為 bug），挑出與我們範圍有關的。向量庫、特定廠商模型代號過期這類問題，等做到對應功能再補。

狀態欄只有三種：「不通過」是已讀程式確認有同樣問題；「待測」是還沒寫測試；「已有」是現有測試涵蓋。

## 怎麼用

- 每寫完一項測試，把「狀態」改成「已有」並寫測試名稱。
- 每項新功能（串流、多家模型、記憶、向量庫）開工前，先回來查這張表有沒有相關項目。
- 每個測試要附陰性對照：故意改壞程式，測試必須失敗。
- Rig 之後有新 issue 時，定期重查並補進來。
