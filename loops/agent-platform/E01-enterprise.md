# E01 身分政策、隔離、稽核、秘密

母檔：../agent-platform.loop.md。依賴 P01。對應 docs/design/architecture.md 的「身分與企業政策」「授權與工具閘門」「隔離與秘密」「診斷、稽核與支援」；企業門檻見 PLAN.md「企業正式發布門檻」。

## 目標

政策不藏在提示詞；操作者不能改管理政策；工具在隔離範圍內跑；稽核可追查且不洩漏秘密。
