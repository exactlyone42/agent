# P02m MCP 工具接入與自動安裝

母檔：../agent-platform.loop.md。依賴 P02、E01；2026-11-05 改以 P05a 知識能力為第三優先成果，本項按實際整合依賴排入，不屬模型供應商轉接。

## 目標

MCP（外部程式提供工具的標準協定）沿用內建工具的批准、取消與回執；使用者從 CLI 安裝、診斷並執行工具，不手工拼接設定。

## 子任務

| id  | 做什麼                                                        | 驗收                                                                                               | 狀態    |
| --- | ------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- | ------- |
| T1  | 核對現成套件版本與授權；定工具、參數、結果及錯誤契約          | 外部工具包成既有 Tool 介面，不重造核心迴圈                                                         | PENDING |
| T2  | 先接標準輸入輸出，再接 HTTP；限制工具發現數量、內容大小與逾時 | 工具列舉、呼叫、壞參數、斷線與不合法回應各有正反例                                                 | PENDING |
| T3  | 批准、隔離、取消與回執整合                                    | 未批准不執行；參數變動拒絕；取消後無新增寫入；未知結果不重送                                       | PENDING |
| T4  | CLI 自動安裝、版本固定、設定與健康檢查                        | 顯示來源、版本、授權及影響；依允許範圍安裝；同版重跑不重複設定                                     | PENDING |
| T5  | 安裝失敗及程序生命週期                                        | 缺依賴、斷網、不完整下載、啟動失敗可辨識；保留原設定，不留下假就緒或孤兒程序；常駐只在容器且綁本機 | PENDING |
| T6  | 乾淨 Linux 帳號完整使用                                       | 安裝→發現工具→批准→執行→獨立讀回；拒絕、取消及崩潰案例通過，秘密零洩漏                             | PENDING |

## 完成條件

T1–T6 通過。HTTP 與標準輸入輸出分開報；真人操作未驗就明列。安裝不擴張花費、刪除或改寫真實資料的授權；失敗先查狀態，不盲重送。P03a 再驗原生套件安裝，不以開發環境成功代替乾淨帳號驗收。
