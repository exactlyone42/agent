# P03a Linux 安裝（內部預覽）

母檔：../agent-platform.loop.md。依賴 P02m。

## 目標

乾淨帳號在 Linux x64 能安裝原生 CLI 並完成首次任務，不需 Node、Rust、PostgreSQL。

| --- | ----------------------------------------- | ------------------------------------------------------------------ | ------- |

## 完成條件

標為內部預覽；不宣稱知識版完成。依使用者先前決定，當前預覽不以簽章為前置；正式簽章要求仍留發布門檻。缺機器或權限時標待解依賴，不改成後續選配。

## 同步依賴與驗收邊界（2026-11-04）

依賴 P02m；乾淨帳號須能使用同版核心與已驗證的 MCP 安裝入口。MCP 安裝驗收沿用 P02m，不要求使用者自行拼裝；本階段仍是內部預覽。
